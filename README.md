One line of office comedy: an out-of-office reply says the writer is on
leave until Monday — and the boss answers it at 11:58 PM on a Saturday,
asking for a quick call.

## Entry

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads it
back and verifies it byte-for-byte. The gate requires a single line of
1–199 UTF-8 characters; anything else exits non-zero.

## Run

```sh
python3 main.py
```
